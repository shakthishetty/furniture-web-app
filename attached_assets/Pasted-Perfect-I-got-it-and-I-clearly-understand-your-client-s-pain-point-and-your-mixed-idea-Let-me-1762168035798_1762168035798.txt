## 🧩 Problem Summary (in short)

Your client doesn’t want to **repeatedly add customization options (Wood Types, Stains, Fabrics, Hardware, Surface Finishes)** every time they create a new product.
He wants a **centralized system** — a one-time setup where all such materials exist globally and can be reused while creating or editing products.

---

## ✅ Proposed Solution: Centralized **“Assets” Module**

### 1. Create a new main section in the Admin Sidebar called **“Assets”**

This is a **global storage system** for all product customization materials.

#### Inside **Assets**, there will be 5 sub-sections:

* **Wood Types**
* **Wood Stains**
* **Fabrics**
* **Hardware**
* **Surface Finishes**

Each of these 5 sections works in the same logical pattern (CRUD — Create, Read, Update, Delete).

---

### 2. Inside Each Subsection (Example: “Wood Types”)

Admins can:

* ✅ View a **list of available wood types**
* ✅ Each entry shows:

  * Wood name (e.g., “Teak”, “Sheesham”, “Oak”)
  * Wood image (so user & admin can visually identify it)
* ✅ Add a **new wood type**

  * Fields:

    * Name
    * Upload Image (preview shown)
* ✅ Edit existing wood types

  * Change name
  * Change or update the image
* ✅ Delete any wood type

---

### 3. Default Indian Market Options (Preloaded)

When database is first seeded, the **Assets** module automatically gets **default standard Indian market options** for all five asset types:

Example defaults:

| Asset Type | Default Options (with image)                |
| ---------- | ------------------------------------------- |
| Wood Type  | Teak, Sheesham, Oak, Rosewood, Mahogany     |
| Stain      | Natural, Walnut, Honey, Wenge, Dark Teak    |
| Fabric     | Cotton, Velvet, Linen, Jute                 |
| Hardware   | Brass, Stainless Steel, Black Matte, Chrome |
| Finish     | Matte, Glossy, Semi-Gloss, Satin            |

These defaults come **preloaded with representative images** (can be edited later).

Admins can **add new**, **delete**, or **replace** these options anytime.

## 🛋️ How It Connects with Product Creation

### 4. Product Creation Page (under “Products → Create Product”)

Keep everything **as it already is now** —
(Product Name, Description, Price, Category, Stock Count, Images, 3D model, PDF, etc.)

But add one more smart feature under the customization part:

#### ➕ Customization Options

When admin clicks **“Add Wood Type / Fabric / Hardware / Finish”** —
Instead of manually typing them every time, show a **dropdown list** populated from the **Assets module**.

* Admin selects from already-existing options in **Assets**.
* The product stores the relationship — not the duplicate data.
* The product only *references* those assets.

---

### 5. Flexibility for Admins

* Admin can still **add a new option** directly from the Assets module (not inside the product form — to keep product form clean).
