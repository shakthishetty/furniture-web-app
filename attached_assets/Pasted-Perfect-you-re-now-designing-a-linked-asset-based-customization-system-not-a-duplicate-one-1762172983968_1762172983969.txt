## 🧱 1️⃣ Concept Overview

Currently your “Create Product” form has fields like:

* Product name, description, price
* Images, PDFs, 3D model upload
* Customization parts (Wood type, Fabric, Hardware, Finish, etc.)

We’ll now connect the “Customization” options to the **Assets module**, so instead of typing each time — the admin picks from existing items in the Assets table.

👉 **Goal:**
Each product record *references* existing `asset.id` (for wood/fabric/etc.) instead of storing new ones.

---

## ⚙️ 2️⃣ Database Design (Drizzle ORM)

You already have:

* `products`
* `assets`

Now, create a **link table** `product_assets` to connect them (many-to-many):

```ts
// server/db/schema/productAssets.ts
import { pgTable, integer, serial, text } from "drizzle-orm/pg-core";
import { products } from "./products";
import { assets } from "./assets";

export const productAssets = pgTable("product_assets", {
  id: serial("id").primaryKey(),
  productId: integer("product_id").references(() => products.id, { onDelete: "cascade" }),
  assetId: integer("asset_id").references(() => assets.id, { onDelete: "cascade" }),
  type: text("type").notNull(), // e.g. 'wood', 'fabric', 'hardware', 'finish'
});
```

Run:

```bash
npm run db:push
```

## ⚙️ 3️⃣ Backend Routes

Add one new route file:

```ts
// server/routes/productAssets.ts
import express from "express";
import { db } from "../db";
import { productAssets } from "@shared/schema";

const router = express.Router();

// POST /api/product-assets
router.post("/", async (req, res) => {
  const { productId, assetId, type } = req.body;

  if (!productId || !assetId || !type)
    return res.status(400).json({ error: "Missing fields" });

  const [created] = await db
    .insert(productAssets)
    .values({ productId, assetId, type })
    .returning();

  res.json(created);
});

// GET /api/product-assets/:productId
router.get("/:productId", async (req, res) => {
  const { productId } = req.params;
  const result = await db.query.productAssets.findMany({
    where: (fields, { eq }) => eq(fields.productId, Number(productId)),
  });
  res.json(result);
});

export default router;
```

Then in your main server entry:

```ts
import productAssetRoutes from "./routes/productAssets";
app.use("/api/product-assets", productAssetRoutes);
```

## ⚙️ 4️⃣ Frontend (React → Admin “Create Product” Page)

When admin adds a new product:

1️⃣ Keep the existing “Upload Image / PDF / 3D model” section.
2️⃣ Below it, add a **Customization Options** section:

```tsx
// CreateProductModal.jsx
import { useEffect, useState } from "react";

function CustomizationSelector({ label, type, selected, onSelect }) {
  const [options, setOptions] = useState([]);

  useEffect(() => {
    fetch(`/api/assets?type=${type}`)
      .then(res => res.json())
      .then(setOptions);
  }, [type]);

  return (
    <div>
      <label>{label}</label>
      <select
        className="border rounded-md p-2 w-full"
        value={selected || ""}
        onChange={(e) => onSelect(type, e.target.value)}
      >
        <option value="">Select {label}</option>
        {options.map(opt => (
          <option key={opt.id} value={opt.id}>
            {opt.name || opt.url.split("/").pop()}
          </option>
        ))}
      </select>
    </div>
  );
}
```

Now integrate it into your form UI:

```tsx
<CustomizationSelector label="Wood Type" type="wood" onSelect={handleSelect} />
<CustomizationSelector label="Fabric Type" type="fabric" onSelect={handleSelect} />
<CustomizationSelector label="Hardware Finish" type="hardware" onSelect={handleSelect} />
<CustomizationSelector label="Surface Finish" type="finish" onSelect={handleSelect} />
```

Store selections in local state:

```tsx
const [selectedAssets, setSelectedAssets] = useState({});
const handleSelect = (type, assetId) => {
  setSelectedAssets(prev => ({ ...prev, [type]: assetId }));
};
```

## ⚙️ 5️⃣ Link on Save (After Creating Product)

When product creation succeeds:

```tsx
const handleCreateProduct = async () => {
  const res = await fetch("/api/products", { ... });
  const newProduct = await res.json();

  // Link assets
  for (const [type, assetId] of Object.entries(selectedAssets)) {
    await fetch("/api/product-assets", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ productId: newProduct.id, assetId, type }),
    });
  }

  alert("✅ Product created and linked with assets!");
};
```

## 🪄 6️⃣ Automatic Reflection on Update

Since products reference the assets by `assetId`,
if the admin edits an asset (name, image, etc.) inside the **Assets** module,
those changes reflect automatically in every product that’s linked to it.

No duplication — only references 🔁
